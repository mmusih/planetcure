# Planetcure Projects website

Static company website with a Kweneng International parent app information page.

## Publishing

Upload the HTML files, `assets/` and `fonts/` to the document root for planetcureprojects.com. Back up existing files first and preserve unrelated hosting configuration and domain verification files. No build step is required.

`index.html` serves the domain root. Keep it synchronized with `Home.html` when editing the homepage. Existing links to `Home.html` remain supported.

## App information

`Apps.html` identifies Planetcure Projects (Pty) Ltd. as publisher, DB Systems as developer, and Kweneng International Secondary School as the customer. Parent support is directed to admin@kwenenginternational.com.

This repository contains public website files only. It does not include a finalized app privacy policy. Publishing these files does not establish Google Play compliance.

These are edited static exports. Re-exporting from an older Mobirise project can overwrite the app page and navigation changes.
